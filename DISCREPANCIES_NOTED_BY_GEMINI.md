# Discrepancies in REFERENCE_MODEL_FOR_GITHUB.md

Based on a critical analysis of the `REFERENCE_MODEL_FOR_GITHUB.md` document, here are the significant discrepancies, ranging from fundamental logical flaws in the Reinforcement Learning (RL) formulation to mathematical and physical modeling errors.

### 1. Causality Paradox in the MDP Formulation (Critical Flaw)
There is a fundamental "chicken-and-egg" causality violation in how the Markov Decision Process (MDP) is structured.
* **The Issue:** In **Section 6.1**, the state $s_t$ includes the current frame's CFO estimate $\hat{\epsilon}_t$, the instantaneous channel gain $|H_t|^2$, and $\mathrm{SNR}_t$. The RL agent uses $s_t$ to select an action $a_t = (\rho_t, \beta_t)$. 
* **The Paradox:** To construct $s_t$, the system must observe the received signal $Y_t$ to estimate $\hat{\epsilon}_t$ and $|H_t|^2$. However, the received signal $Y_t$ is a direct result of the transmitted signal $X_t$ (Eq. 3), which requires the agent to have **already chosen** the action $(\rho_t, \beta_t)$ to format the pilot and data symbols (Eq. 2). 
* **Conclusion:** The agent cannot observe the outcome of an action before taking that action. The state definition must use delayed observations (e.g., $s_t = [\hat{\epsilon}_{t-1}, \dots]$) to be causally valid.

### 2. Unobservability of State Variables
* **The Issue:** **Section 6.1** explicitly states that "The state vector captures all relevant **measurable** quantities required for decision making," yet it includes $\tilde{\epsilon}_t^2$ (the squared residual CFO error) in the state vector (Eq. 19).
* **The Discrepancy:** By definition (Eq. 9), the residual error is $\tilde{\epsilon}_t = \epsilon_t - \hat{\epsilon}_t$. The true CFO $\epsilon_t$ is fundamentally unknown to the receiver. If the system could measure its own estimation error $\tilde{\epsilon}_t^2$ at runtime, it would effectively know the true CFO and could correct it perfectly, rendering the entire estimation problem obsolete. While this variable can be used in a simulated *reward function* during training, it is strictly unobservable and cannot be part of the agent's *state space* during execution.

### 3. Mathematical Error in CFO Estimator Averaging
* **The Issue:** In **Section 2.1**, the least-squares CFO estimator (Eq. 7) computes the phase difference between consecutive OFDM symbols. The inner summation goes from $n=1$ to $N-1$.
* **The Discrepancy:** A sum from $1$ to $N-1$ produces exactly **$N-1$ terms**. However, the formula averages the result by dividing by $\frac{1}{|\mathcal{P_t}|N}$. Because there are only $|\mathcal{P_t}|(N-1)$ total phase differences calculated, dividing by $N$ instead of $(N-1)$ artificially scales down the estimate, resulting in a **biased** estimator. It should divide by $\frac{1}{|\mathcal{P_t}|(N-1)}$.

### 4. Inconsistent Physical Modeling of Interference (ICI)
* **The Issue:** There is a disconnect in how channel fading affects the signal versus how it affects self-interference.
* **The Discrepancy:** In **Section 3.1 (Eq. 10)**, the Inter-Carrier Interference (ICI) power is modeled as $\sigma^2_{\mathrm{ICI},t} \approx C \cdot \tilde{\epsilon}_t^2 P_t$, depending only on the transmit power $P_t$. However, in **Section 3.2 (Eq. 11)**, the data signal power in the SINR numerator is correctly subjected to channel fading: $(1-\beta_t)P_t |H_t|^2$. 
Because ICI is self-interference generated by the transmitted signal passing through the *same channel*, the received ICI power should also scale with the channel gain $|H_t|^2$. By adding $\sigma^2_{\mathrm{ICI},t}$ directly to the thermal noise without the channel gain, the model incorrectly implies that ICI is immune to channel fading.

### 5. Undefined Variables and Ambiguous Terms
* **Undefined SNR:** **Section 6.1** includes $\mathrm{SNR}_t$ in the state definition (Eq. 19). However, a generic $\mathrm{SNR}_t$ is never defined in the text. The text only defines $\mathrm{SINR}_t$ for data communications (Eq. 11) and $\mathrm{SNR}_{\mathrm{pilot}}$ for sensing (Eq. 14). It is ambiguous which one the agent is supposed to observe.
* **Variable Misalignment in Reward:** In **Section 5 (Eq. 15)**, the reward function penalizes based on $\mathrm{Var}(\hat{\tau}_t)$. However, in Section 4.1 (Eq. 13), $\mathrm{Var}(\hat{\tau}_t)$ is defined as a theoretical inequality (a Cramér–Rao Lower Bound with a $\ge$ sign). Mixing an actual measured error $\tilde{\epsilon}_t^2$ with a theoretical lower bound $\mathrm{Var}(\hat{\tau}_t)$ in the same instantaneous reward function is conceptually inconsistent; the reward should theoretically rely on the actual measured sensing error if evaluated in a simulation.
