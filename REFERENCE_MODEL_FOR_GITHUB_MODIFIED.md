# Reinforcement Learning-Based Adaptive Pilot and Power Allocation for Joint Synchronization and Sensing in OFDM-ISAC Systems

## Abstract
This paper proposes a reinforcement learning-based adaptive pilot and power allocation framework for joint synchronization and sensing in OFDM-based Integrated Sensing and Communication (ISAC) systems. Unlike conventional systems where pilot density and power allocation are fixed, the proposed framework dynamically adapts these parameters based on channel conditions and synchronization quality. A mathematical system model incorporating time-varying carrier frequency offset (CFO), multipath fading, and additive noise is developed. The tradeoff between communication rate, synchronization accuracy, and sensing precision is analytically characterized. The adaptive control problem is formulated as a Markov Decision Process (MDP) and solved using Deep Q-Network (DQN). The proposed approach enables intelligent closed-loop physical layer adaptation and demonstrates significant performance gains over fixed pilot schemes.

## 1 System Model
We consider a single-input single-output (SISO) Orthogonal Frequency Division Multiplexing (OFDM)-based Integrated Sensing and Communication (ISAC) system. The system operates in discrete time frames indexed by $t$. Each frame consists of $N$ OFDM symbols and $K$ subcarriers. The constant average transmit power per OFDM symbol is denoted by $P$. The system dynamically allocates a fraction of subcarriers for pilot transmission and distributes transmit power between pilot and data symbols.

### 1.1 OFDM Transmission Model
Let $\rho_t \in (0, 1)$ denote the pilot ratio at frame $t$. Then, the number of pilot subcarriers is:

$$|\mathcal{P}_t| = \rho_t K \quad (1)$$

The remaining $(1 - \rho_t)K$ subcarriers are used for data transmission.
The transmitted OFDM symbol at subcarrier $k$ and OFDM symbol index $n$ is given by:

$$X_t[k,n] = \begin{cases} \sqrt{\dfrac{\beta_t P}{\rho_t K}}\, s_p[k,n], & k \in \mathcal{P}_t \\ \\ \sqrt{\dfrac{(1-\beta_t)P}{(1-\rho_t)K}}\, s_d[k,n], & k \in \mathcal{D}_t \end{cases} \quad (2)$$

where:
* $\beta_t \in (0, 1)$ is the fraction of total power allocated to pilots,
* $s_p[k, n]$ and $s_d[k, n]$ are unit power pilot and data symbols respectively,
* $\mathcal{P}_t$ and $\mathcal{D}_t$ denote pilot and data index sets.

**Explanation:**
The above equation defines the adaptive pilot and power allocation mechanism. The parameter $\rho_t$ determines how many subcarriers are dedicated to synchronization and sensing functions through pilot transmission. The parameter $\beta_t$ controls the fraction of total transmit power devoted to pilot signals, which directly affects estimation accuracy. By scaling pilot symbols with $\sqrt{\dfrac{\beta_t P}{\rho_t K}}$, the total pilot power equals $\beta_t P$, ensuring power normalization. Similarly, the data subcarriers receive total power $(1 - \beta_t)P$. This structure ensures that total transmit power constraint is satisfied at every frame. Importantly, $\rho_t$ and $\beta_t$ are treated as adaptive control variables rather than fixed parameters. This adaptive structure forms the basis of the reinforcement learning framework proposed later.

### 1.2 Channel and Impairment Model
The received signal at subcarrier $k$, symbol $n$, and frame $t$ is modeled as:

$$Y_t[k,n] = H_t X_t[k,n] e^{j 2\pi \epsilon_t n T_s} + W_t[k,n] \quad (3)$$

where:
* $H_t$ is the block-fading channel frequency response, assumed flat across subcarriers and constant over the frame,
* $\epsilon_t$ is the carrier frequency offset (CFO) in Hz,
* $T_s$ is the OFDM symbol duration,
* $W_t[k, n] \sim \mathcal{CN}(0, \sigma^2)$ is additive white Gaussian noise.

**Explanation:**
The received signal model incorporates both multipath fading and synchronization impairments. For mathematical tractability in the subsequent system-level analysis, we assume a block-fading channel where the channel response $H_t$ is approximately flat across subcarriers and time-invariant over the frame duration. While Equation (3) presents a simplified view without explicitly showing adjacent subcarrier interference, the inter-carrier interference (ICI) generated by the CFO will be accounted for later as an equivalent additive noise term. The exponential term $e^{j 2\pi \epsilon_t n T_s}$ represents carrier frequency offset, which causes phase rotation across OFDM symbols. The CFO parameter $\epsilon_t$ is assumed to be time-varying due to oscillator drift. Additive white Gaussian noise is assumed with variance $\sigma^2$, which affects both communication and sensing accuracy.

### 1.3 CFO Dynamics
We model the CFO evolution as a random walk process:

$$\epsilon_{t+1} = \epsilon_t + \nu_t \quad (4)$$

$$\nu_t \sim \mathcal{N}(0,\sigma_\nu^2) \quad (5)$$

**Explanation:**
The CFO process is modeled as a discrete-time stochastic process to capture oscillator instability. The random walk assumption is widely used for modeling slow frequency drift in practical oscillators. The innovation term $\nu_t$ represents small random fluctuations between frames. The variance $\sigma_\nu^2$ determines how rapidly the CFO varies over time.

## 2 Synchronization and Sensing Estimation
### 2.1 CFO Estimation Using Pilot Symbols
To estimate the carrier frequency offset (CFO), we utilize pilot subcarriers. Considering two consecutive OFDM symbols, and assuming pilot symbols are identical across these consecutive symbols ($s_p[k,n+1] = s_p[k,n]$), we compute the phase difference:

$$\angle\!\left(\dfrac{Y_t[k,n+1]}{Y_t[k,n]}\right) \approx 2\pi \epsilon_t T_s + \eta_{k,n} \quad (6)$$

where $\eta_{k,n}$ represents noise-induced phase error.
A least-squares CFO estimator is given by:

$$\hat{\epsilon}_t = \dfrac{1}{2\pi T_s}\cdot \dfrac{1}{|\mathcal{P}_t|(N-1)}\sum_{k\in \mathcal{P}_t}\sum_{n=1}^{N-1}\angle\!\left(\dfrac{Y_t[k,n+1]}{Y_t[k,n]}\right) \quad (7)$$

**Explanation:**
The above estimator leverages phase rotation between consecutive OFDM symbols to estimate CFO. The estimator relies on the assumption that pilot symbols are repeated and the channel stays relatively constant across consecutive symbols. Because there are $N-1$ consecutive pairs in $N$ symbols, the normalization properly averages over $|\mathcal{P}_t|(N-1)$ observations to yield an unbiased estimate. As $\rho_t$ increases, the estimator variance decreases due to increased averaging. 

Following CFO compensation, the flat-fading channel $H_t$ is estimated using standard least-squares over the same pilot subcarriers. For the purposes of the MDP state representation and bounding analysis, we assume the residual channel estimation error is negligible compared to the CFO impairment, such that the estimated channel magnitude is approximately perfect: $|\hat{H}_t|^2 \approx |H_t|^2$. 

### 2.2 CRLB of CFO Estimation
Under the Gaussian noise assumption, the Cramér–Rao Lower Bound (CRLB) for the CFO estimator variance is given by:

$$\mathrm{CRLB}(\hat{\epsilon}_t) = \dfrac{\sigma^2}{2(2\pi T_s)^2 \beta_t P \rho_t K (N-1)} \quad (8)$$

**Explanation:**
The above expression represents the Cramér–Rao Lower Bound (CRLB) for unbiased CFO estimation. The bound is proportional to the number of consecutive phase difference observations, which is $N-1$ per subcarrier. The bound shows that estimation variance decreases with increasing pilot power $\beta_t P$ and increasing pilot density $\rho_t$. The inverse proportionality structure clearly shows the fundamental tradeoff: synchronization accuracy improves when more pilot resources are used, but reduces data-carrying capacity.

## 3 Communication Performance Analysis
### 3.1 Residual CFO and ICI Power
Let the residual synchronization error be:

$$\tilde{\epsilon}_t = \epsilon_t - \hat{\epsilon}_t \quad (9)$$

The inter-carrier interference (ICI) power caused by residual CFO can be approximated as:

$$\sigma^2_{\mathrm{ICI},t} \approx C \cdot \tilde{\epsilon}_t^2 P |H_t|^2 \quad (10)$$

where $C \approx \dfrac{\pi^2}{3 (\Delta f)^2}$ is a proportionality constant derived from standard OFDM interference models, with $\Delta f$ being the subcarrier spacing.

**Explanation:**
Residual CFO after estimation introduces imperfect orthogonality among subcarriers. This effect produces inter-carrier interference (ICI), which degrades the effective signal-to-interference-plus-noise ratio (SINR). The scaling by total transmit power and the channel gain $|H_t|^2$ is critical, as the self-interference propagates through the exact same fading channel as the desired signal.

### 3.2 Achievable Data Rate
The effective SINR at frame $t$ is:

$$\mathrm{SINR}_t = \dfrac{(1-\beta_t)P |H_t|^2}{\sigma^2 + \sigma^2_{\mathrm{ICI},t}} \quad (11)$$

The normalized spectral efficiency (bps/Hz) is:

$$R_t = (1-\rho_t)\log_2(1+\mathrm{SINR}_t) \quad (12)$$

**Explanation:**
The numerator reflects power allocated to data symbols. The denominator includes thermal noise and residual ICI power. The factor $(1 - \rho_t)$ accounts for the fraction of subcarriers available for data transmission. If pilot density increases excessively, spectral efficiency decreases. However, increasing pilots reduces synchronization error, indirectly increasing SINR. 

## 4 Sensing Performance Analysis
### 4.1 CRLB of Delay Estimation
The Cramér–Rao Lower Bound (CRLB) for delay estimation variance satisfies:

$$\mathrm{CRLB}(\hat{\tau}_t) = \dfrac{1}{8\pi^2 B^2 \cdot \mathrm{SNR}_{\mathrm{pilot}} \cdot \rho_t K N} \quad (13)$$

where:

$$\mathrm{SNR}_{\mathrm{pilot}} = \dfrac{\beta_t P}{\sigma^2} \quad (14)$$

**Explanation:**
The delay estimation bound is derived from radar estimation theory. The parameter $B$ represents signal bandwidth. The sensing CRLB relies on the effective time-bandwidth product, which is directly proportional to the number of pilot subcarriers ($\rho_t K N$). Thus, both pilot density ($\rho_t$) and pilot power ($\beta_t$) jointly dictate the sensing resolution. This establishes the full sensing-communication tradeoff.

## 5 Problem Formulation
We aim to design adaptive pilot ratio $\rho_t$ and pilot power fraction $\beta_t$ to maximize long-term system utility.
To avoid training instabilities caused by unobservable instantaneous error realizations, we define the immediate reward $r_t$ using the theoretical CRLB proxies for variance:

$$r_t = \lambda_1 R_t - \lambda_2 \mathrm{CRLB}(\hat{\epsilon}_t) - \lambda_3 \mathrm{CRLB}(\hat{\tau}_t) \quad (15)$$

The objective is:

$$\max_{\{\rho_t,\beta_t\}} \mathbb{E}\!\left[\sum_{t=0}^{\infty}\gamma^t r_t\right] \quad (16)$$

subject to:

$$0 < \rho_t < 1 \quad (17)$$

$$0 < \beta_t < 1 \quad (18)$$

**Explanation:**
The reward function incorporates three competing objectives: communication rate, expected synchronization accuracy, and expected sensing precision. Using theoretical variances rather than specific unobservable error realizations ($\tilde{\epsilon}_t^2$) ensures consistent abstraction levels and provides a stable gradient for RL training. The weight parameters $\lambda_1$, $\lambda_2$, and $\lambda_3$ control system priorities. 

## 6 Markov Decision Process Formulation
The adaptive pilot and power allocation problem is formulated as a Markov Decision Process (MDP) defined by the tuple $(\mathcal{S}, \mathcal{A}, \mathcal{P}, r, \gamma)$.

### 6.1 State Space Definition
To preserve strict causality, the agent must make decisions for frame $t$ based entirely on observables from the completed frame $t-1$. We define the baseline system SNR as $\mathrm{SNR} = P / \sigma^2$. The state at frame $t$ is:

$$s_t = [\,\hat{\epsilon}_{t-1}, \mathrm{CRLB}(\hat{\epsilon}_{t-1}), |\hat{H}_{t-1}|^2, \rho_{t-1}, \beta_{t-1}\,] \quad (19)$$

**Explanation:**
The state vector strictly uses delayed observations to prevent causality loops (i.e., observing the outcome of an action before choosing it). The previously estimated CFO $\hat{\epsilon}_{t-1}$ and channel magnitude $|\hat{H}_{t-1}|^2$ provide actionable temporal correlations due to the system's Markovian dynamics. The theoretical bound $\mathrm{CRLB}(\hat{\epsilon}_{t-1})$ implicitly informs the agent of its estimation confidence. The inclusion of previous actions $\rho_{t-1}$ and $\beta_{t-1}$ helps the agent map its past decisions to current observations. The baseline system SNR is treated as a known environmental constant and is thus omitted from the dynamic state vector. 

### 6.2 Action Space Definition
We discretize the control variables for DQN implementation:

$$\rho \in \{0.1,0.2,0.3,0.4\} \quad (20)$$

$$\beta \in \{0.2,0.4,0.6\} \quad (21)$$

Thus, the total action space size is:

$$|\mathcal{A}| = 12 \quad (22)$$

**Explanation:**
Discretization simplifies neural network output design and ensures stable learning. The ranges reflect practical constraints, preserving system nonlinearity while ensuring feasibility.

### 6.3 State Transition Model
The CFO evolution follows:

$$\epsilon_{t+1} = \epsilon_t + \nu_t \quad (23)$$

Channel evolution is modeled as block fading:

$$H_{t+1} = \alpha H_t + \sqrt{1-\alpha^2}\, z_t \quad (24)$$

where $z_t \sim \mathcal{CN}(0, 1)$ and $\alpha$ determines temporal correlation.

## 7 Deep Q-Network Solution
### 7.1 Action-Value Function
The optimal action-value function satisfies the Bellman optimality equation:

$$Q^{\ast}(s_t, a_t) = \mathbb{E} \left[ r_t + \gamma \max_{a'} Q^{\ast}(s_{t+1}, a') \mid s_t, a_t \right] \quad (25)$$

### 7.2 Neural Network Approximation
We approximate $Q(s, a)$ using a neural network parameterized by $\theta$:

$$Q(s,a;\theta) \quad (26)$$

The loss function for training is:

$$L(\theta) = \mathbb{E}\!\left[\left(r_t + \gamma \max_{a'} Q(s_{t+1},a';\theta^{-}) - Q(s_t,a_t;\theta)\right)^2\right] \quad (27)$$

where $\theta^{-}$ represents the target network parameters.

4 : **for** each episode **do**<br>

## 9 Discussion on Convergence and Stability

While standard DQN with nonlinear function approximation lacks formal mathematical convergence guarantees, the integration of experience replay and target networks empirically stabilizes the learning process. The bounded action space ensures finite Q-values, and formulating the reward using theoretically bounded expected variances avoids the high-variance jumps typical of using instantaneous error realizations. Because the CFO dynamics and block fading channels maintain temporal correlation, the agent can reliably track slow drift over consecutive frames. This provides a robust and empirically stable adaptive solution for the joint synchronization-sensing optimization problem.
